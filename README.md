Buscador de Películas y Series

Aplicación web desarrollada en HTML, Sass y JavaScript que permite buscar información de películas y series utilizando la API de TVMaze.  
El usuario puede consultar títulos, ver detalles, visualizar imágenes y obtener información relevante como género, fecha de lanzamiento
y calificación.

- Funcionalidades

- Búsqueda en tiempo real** de películas y series.
- Tarjetas dinámicas** con imagen, título, género, fecha y rating.
- Modal de detalles** con información ampliada.
- Diseño responsivo** adaptado para móviles y tablets.
- Interfaz moderna** creada con Sass, variables, sombras y transiciones.
- Consumo de API externa (TMDb)** mediante `fetch`.

- Tecnologías utilizadas

- HTML5**
- Sass (SCSS)**
- JavaScript Vanilla**
- TVMaze API**
- Firebase Hosting**
- Git & GitHub**

- Diseño

La aplicación utiliza una paleta de colores basada en tonos azules para lograr una interfaz moderna, limpia y profesional.  
El diseño incluye:

- Tipografías: *Inter* y *Poppins*  
- Sombras suaves y elevación en tarjetas  
- Layout responsivo con `grid` y `clamp()`  
- Animaciones sutiles en el modal
